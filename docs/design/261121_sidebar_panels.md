# Simple GTD のサイドバー向けパネル配置

- Status: Proposed
- Date: 2026-11-21

## 目的

Simple GTD を VS Code の狭いサイドバーに収まる構成にする。[ブラウザ版 UI の設計](261121_spa_ui.md)のパネル配置、カードまわりの操作ボタン、パネル間移動の演出を更新する。

## 現在の決定

### 仕様

#### パネルの配置と開閉

Inbox、TODOs、TADAs は上からこの順に並ぶ。3つとも枠全体が見える。選択中のパネルが残りの高さを使い、他のパネルはヘッダーの高さに縮む。縮んだパネルのヘッダーを選ぶと、そのパネルが開く。

#### スタックのカードと操作ボタン

Inbox の Project ボタンは先頭カードの左下、Next Actions の後回しボタンは先頭カードの左上に置く。後回しボタンには Redo アイコンを使う。Inbox と Next Actions のカードは TADAs のカードと同じ幅で、パネル内の利用できる幅まで広げる。最大幅は 32 rem とする。アイコンだけのボタンは、ホバーまたはキーボードフォーカス時にツールチップで用途を表示する。

#### パネル間のカード移動

カードは移動先パネルの内側に入り、到着時にパネルが移動方向へ小さく動いて元の位置に戻る。移動先が閉じている場合は、そのヘッダーの内側に入る。動きを減らす設定では移動と到着時の動きを省く。

### 設計

ブラウザ版と VS Code サイドバーで共有する SPA のパネル配置を変更する。

## 重要な代替案

### 隣接するパネルの見切れ

- 対応する決定: [パネルの配置と開閉](#パネルの配置と開閉)
- Alternative: Inbox と TODOs を左右に並べ、閉じているパネルは画面端に一部を表示する。
- 棄却根拠: VS Code の狭いサイドバーで3つのパネルを常に同じ順序で選べる縦並びを採用した。
